# Соответствие требованиям документа

Здесь отмечено наличие реализации в исходном коде. Это не полный протокол приёмки: выборочные браузерные проверки описаны в [ACCEPTANCE.md](ACCEPTANCE.md); интеграционные проверки конкурентности и нагрузочные измерения не выполнялись.

| Требование                     | Реализация                                                                       |
| ------------------------------ | -------------------------------------------------------------------------------- |
| FR-01 Регистрация и доступ     | `/auth/*`, Argon2id, сессии, CSRF, роли                                          |
| FR-02 Профиль и права          | `/me`, `/admin/users`, настройки профиля                                         |
| FR-03 События организатора     | черновик, изменение, публикация, кабинет организатора                            |
| FR-04 Поиск и карта            | совместные фильтры, пагинация 20, карта до 200 точек, отказ подложки             |
| FR-05 Карточка и отмена        | карточка с условиями, причина отмены, уведомление                                |
| FR-06 Запись и места           | блокировка строки события, уникальная запись, восстановление                     |
| FR-07 Отмена и список          | собственная отмена, список только владельцу                                      |
| FR-08 Подтверждение            | attended/no_show, ограничения срока и показателей                                |
| FR-09 Баллы                    | формулы по типам, бонус организатору, журнал проводок                            |
| FR-10 Вклад и история          | профиль, часы, кг, деревья, проводки и баланс                                    |
| FR-11 Рейтинг и достижения     | заработанные баллы, уровни, уникальные бейджи                                    |
| FR-12 Напоминания              | отдельный scheduler, SMTP, dedupe, подавление отменённых записей                 |
| FR-13 Команды                  | создание, членство, выход, команда записи до начала                              |
| FR-14 Соревнования             | минимум два участника, ранги, общий первый результат, бонус                      |
| FR-15 Фото и отзывы            | текст, JPEG/PNG до 5 МБ, фото до/после и отзывы                                  |
| FR-16 Партнёры и предложения   | публичный каталог, тестовые пометки, кабинеты                                    |
| FR-17 Обмен                    | блокировки пользователя/предложения, ключ идемпотентности, код                   |
| FR-18 Получение награды        | погашение партнёром, ручной/автоматический возврат                               |
| FR-19 Статьи и эколидеры       | публикация, источники, справочник с публичным контактом                          |
| FR-20 Вопрос эксперту          | роли, ответ, уведомление, закрытие                                               |
| FR-21 Подписки и уведомления   | город и типы, новые акции, отмена, ответ, прочтение                              |
| FR-22 Статистика организатора  | записи, явки, неявки и измеренный вклад                                          |
| FR-23 Исправление и завершение | компенсирующие проводки, запрет отрицательного баланса и правки после завершения |
| FR-24 Возвращаемость           | первая запись, полные 14 дней, другое событие, `нет данных`                      |

Технические ограничения и оставшиеся шаги перед формальной приёмкой перечислены в [IMPLEMENTATION.md](IMPLEMENTATION.md). Требования NFR-03, NFR-04, NFR-06, NFR-07 и NFR-09 содержат измерения или проверки на стенде и не могут считаться выполненными только по наличию кода.

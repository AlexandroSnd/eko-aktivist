# Статус реализации

Этот репозиторий создан по аналитическому документу от 17.10.2026. Реализованы модели данных, миграция, API и интерфейс основных разделов: авторизация, мероприятия, запись и отмена, подтверждение, баллы, рейтинг, команды, предложения и коды, статьи, вопросы, уведомления и служебные кабинеты. Seed добавляет десять будущих акций, завершённую и прошедшую незавершённую акцию, две учебные партнёрские организации и пять предложений.

## Что требует завершения до приёмки FR-01–FR-24

- Проверить ограничение попыток входа за обратным прокси в реальном окружении. Предварительный CSRF-токен подписан сервером; пользовательская сессия хранит hash токена.
- Отправка email сейчас идёт внутри транзакции планировщика. Для гарантированного отсутствия дублей при аварии между SMTP и фиксацией состояния нужна отдельная стратегия подтверждения доставки и наблюдение очереди.
- Конкурентные проверки на PostgreSQL для записи на последнее место, обмена, погашения и истечения кода.
- При ошибке записи БД после сохранения фото может остаться файл без ссылки; нужна уборка таких файлов. Загруженные фото сейчас публичны по непрогнозируемому имени.
- Дополнительный аудит транзакций, порядка блокировок и повторов после ошибок БД. Исправление результата при недостаточном балансе возвращает 409; администратор может сначала вернуть непогашенный обмен.
- HTTPS на публичном стенде, замеры NFR, резервное копирование и проверка восстановления, полная браузерная и пользовательская приёмка. Частичная локальная браузерная проверка описана в [ACCEPTANCE.md](ACCEPTANCE.md).

Документ задачи требует всех FR и NFR для полного релиза. Текущий репозиторий — реализация для дальнейшей разработки и интеграции; считать его принятым релизом до закрытия списка выше нельзя.

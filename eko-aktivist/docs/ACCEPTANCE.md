# Браузерная приёмка

Запуск: поднять API на `127.0.0.1:8000`, web на `127.0.0.1:8080`, применить миграции и выполнить `seed_demo`; затем в `apps/web` запустить `npm run test:e2e`. Для первичной установки браузера — `npx playwright install chromium`.

Набор `apps/web/e2e/acceptance.spec.ts` проверяет интерфейс и основные запросы через временную PostgreSQL базу. Матрица показывает глубину выполненных браузерных проверок; частичная проверка не подтверждает все серверные инварианты требования.

| Требование                      | Результат браузерной проверки                                                                                                                                               |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-01 Регистрация и доступ      | Проверены регистрация участника и вход демо-ролей                                                                                                                           |
| FR-02 Профиль и права           | Проверены редактирование профиля и отказ участнику в доступе к админке; назначение ролей проверено для партнёра                                                             |
| FR-03 События организатора      | Проверены создание черновика, редактирование, фото и публикация                                                                                                             |
| FR-04 Поиск и карта             | Проверены маркеры, pan карты, одинаковый bbox для списка и карты, фильтр типа, геолокация, отказ тайлов и мобильный размер; многополевые комбинации фильтров не проверялись |
| FR-05 Карточка и отмена         | Проверены детали акции и отмена организатором с причиной                                                                                                                    |
| FR-06 Запись и места            | Проверена запись участника и запись от команды; гонка за последнее место не проверялась                                                                                     |
| FR-07 Отмена участия и список   | Проверена отмена собственной записи; изоляция чужого списка не проверялась                                                                                                  |
| FR-08 Подтверждение результатов | Проверено подтверждение явки и часов организатором                                                                                                                          |
| FR-09 Начисление баллов         | Проверены баллы, необходимые для обмена; все формулы и повторное начисление не проверялись                                                                                  |
| FR-10 Вклад и история           | Проверены профиль участника, история и публикация отзыва; числовые формулы показателей не сверялись                                                                         |
| FR-11 Рейтинги и достижения     | Проверена страница рейтинга; уровни и уникальность бейджей не проверялись                                                                                                   |
| FR-12 Напоминания               | Не проверялась доставка email и дедупликация планировщика                                                                                                                   |
| FR-13 Команды                   | Проверены создание, вступление, выход и запись на акцию от команды                                                                                                          |
| FR-14 Соревнования              | Проверены наличие командного режима и виджет результатов; ранги, ничьи и бонус победителя не проверялись                                                                    |
| FR-15 Фото и отзывы             | Проверены загрузка фото акции, отзыв и фото отзыва; лимиты размера и MIME проверялись только позитивным случаем                                                             |
| FR-16 Партнёры и предложения    | Проверены каталог и кабинет партнёра; полный CRUD предложения отдельно не проверялся                                                                                        |
| FR-17 Обмен                     | Проверен обмен баллов на учебное предложение с одноразовым кодом                                                                                                            |
| FR-18 Получение награды         | Проверено погашение кода партнёром; возврат и гонка истечения кода не проверялись                                                                                           |
| FR-19 Статьи и эколидеры        | Проверены публикация статьи, её появление в базе знаний и страница эколидеров                                                                                               |
| FR-20 Вопрос эксперту           | Проверены отправка вопроса, назначение права эксперта, ответ и уведомление автора                                                                                           |
| FR-21 Подписки и уведомления    | Проверены сохранение подписки, получение ответа, входящее уведомление и отметка прочтения; email-доставка не проверялась                                                    |
| FR-22 Статистика организатора   | Проверена статистика участников после подтверждения; полный набор показателей не сверялся                                                                                   |
| FR-23 Исправление и завершение  | Проверена корректировка результата до завершения, завершение и отказ в изменении после него                                                                                 |
| FR-24 Возвращаемость            | Проверен расчёт для пустой когорты; точность расчёта на реальных данных не проверялась                                                                                      |

Не выполнялись нагрузочные проверки, проверка гонок конкурентных запросов, доставка через SMTP, резервное копирование и восстановление, матрица браузеров и измерения NFR. Эти проверки требуют отдельного стенда и не подтверждаются локальным Playwright прогоном.
